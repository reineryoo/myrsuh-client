# Контроль требований MyRSUH

Исходное ТЗ от 02.11.2026 сохранено в `docs/ТЗ.md`. Ниже собраны исходные требования и последующие уточнения. Последующие уточнения имеют приоритет.

## Исходные требования

- Отдельные FastAPI / Python 3.12+ и React / TypeScript / Vite.
- Tailwind, shadcn/ui, Lucide, date-fns (ru), TanStack Query.
- Только реальный поток 119_1, конфигурация расширяема. Никаких демонстрационных занятий в приложении.
- Multipart POST к фиксированному API РГГУ, intervalMode=4, eduform=3, course=2, menuMode=flow.
- Все flows и исходные идентификаторы сохраняются. Пары не объединяются.
- Восемь интервалов звонков из ТЗ. Даты и текущие занятия — Europe/Moscow.
- Серверный TTL 900 секунд, объединение параллельных запросов, ограничение обновлений, ограниченный stale fallback.
- API: groups, schedule, schedule/refresh, health. Входные группы ограничены конфигурацией.
- Onboarding и localStorage; день; неделя ПН–ВС; месяц; обзор семестра; сегодня; настройки; две темы.
- Skeleton, error/retry, empty, stale, refresh и две разные метки обновления.
- Mobile-first по уточнению пользователя от 02.11.2026: один интерфейс с центральной областью до 620 px, небольшим расширением на ПК и пустыми боковыми полями. Sidebar удалён. Свайпы дней и доступные элементы управления сохраняются.
- Тесты нормализации, звонков, пустых дней, нескольких flows, дат, сохранения группы, ошибок и кеша.
- Локальный запуск обоих серверов, README. Без БД, аккаунтов, Docker, PWA, уведомлений.

## Проверка интеграции

02.11.2026: публичный endpoint ответил HTTP 200 без сессии. Запрос intervalMode=4 вернул период 24.08.2026–21.03.2027, 76 дней с занятиями. Фактический диапазон используется из ответа, не вычисляется по учебному году.

## Уточнение от 03.11.2026 — актуальный интерфейс

- В нижнем баре ровно три страницы: Главная, Календарь, Настройки. Главная — стартовая; профиль без авторизации открывает настройки. Обращение «Студент», приветствие по московскому времени. Историй нет.
- Главная показывает реальные занятия выбранного дня, первое/следующее и текущее занятие. После окончания или при отсутствии пар — отдельная панель и «План на завтра», рассчитанный из загруженных данных. Прошедшие строки серые.
- Календарь: День / Неделя / Месяц; семестр остаётся доступен кнопкой в заголовке. Дневная красная линия движется по реальному времени с точностью до секунды, по геометрии пар и перерывов. Текущая пара слегка увеличивается, подсвечивается и получает тег «Идёт сейчас». Прошедшие пары затемнены только в списке; неделя и месяц сохраняют исходные цвета.
- Группа вынесена из настроек: меню выбранной группы → Все расписания → поиск по названию и добавление доступной группы. Только реестр реальных API-групп, пока одна. Список выбранных расписаний сохраняется отдельно.
- `лек; сем` — единый тег `ЛЕК · СЕМ` и отдельный тёплый золотистый цвет. Экзамены остаются фиолетовыми.
- Настройки — отдельная страница: тема, звонки, обновление, инструкции iPhone, локальный сброс. Без секции выбора группы.
- iPhone: manifest display=standalone, apple mobile web app meta, touch icon 180 px, icons 192/512, безопасные отступы. Ярлык через Safari «На экран Домой»; без офлайн-режима, push и Service Worker. При локальном запуске нужен включённый ПК и та же сеть.
- Центральная область на ПК расширена до 720 px, поля по бокам остаются пустыми.

## Дополнительные правки от 03.11.2026

- В шапке календаря вместо названия вуза показана выбранная неделя из общего числа недель семестра. Расчёт ведётся по понедельникам в периоде API; за его пределами номер не выдумывается. Подпись направления под «Пары» убрана. Краткое название потока — «ПИ ПИИ», без курса и номера группы в кнопке.
- Общий фон получил едва заметный серый градиент в правом верхнем углу. «Студент» вынесен в отдельный элемент приветствия и окрашен выбранным акцентом.
- Четыре сохраняемых пастельных акцента: голубой, зелёный, красный, фиолетовый. Цвета типов занятий от настройки не зависят.
- «Прошедшие пары вниз» включено по умолчанию: текущие/предстоящие пары сверху, прошедшие серыми ниже. При отключении список сохраняет хронологический порядок и исходные цвета. Это не скрытие занятий. Работает на главной и в дневном календаре; недели/месяцы не затемняются.
- Кнопка сброса локальных данных и её иконка красные. Сброс возвращает голубой акцент и включённое упорядочивание прошедших пар.
- Стрелки дневного календаря листают по одному дню, включая переходы недель, месяцев и годов. Свайпы сохранены; недельный и месячный режимы листают соответствующие периоды.

## Уточнение дизайна от 02.11.2026

Четыре референса пользователя заменяют исходное desktop-first направление ТЗ. Чёрный фон, панели #111113, акцент #A7C4FF, мятные лекции, голубые семинары/практика и фиолетовые экзамены. Главный экран — день, переключатель День / Неделя / Месяц, семестр доступен из нижней навигации. Карточки с временем слева, цветной полосой, всеми исходными данными и реальными перерывами. Цветные точки календаря соответствуют уникальным номерам пар. Функционал изменений недели не добавляется. Нерабочие кнопки из референсов (уведомления, сравнение, карта и т. п.) не копируются.

## Анимации и типографика — 03.11.2026

- Нижняя навигация сохраняет три пункта. Общее выделение плавно перемещается между ними за 300 мс, иконки и нажатия получают сдержанную обратную связь. Геометрия пересчитывается при изменении ширины и загрузке шрифтов.
- Короткое проявление страниц и выбранного дня, мягкое открытие/закрытие подробностей, появление меню групп и уведомлений. Без пружин, постоянной пульсации и задержки переходов. Секундное обновление времени не перезапускает входные анимации.
- Системное «Уменьшение движения» отключает анимации и переходы. Фиксированная кнопка «Сегодня» сохраняет привязку к окну.
- Onest Variable — текст и элементы управления; Manrope Variable — крупные заголовки. Локальные Latin/Cyrillic WOFF2, без запросов к сервисам шрифтов. Лицензии OFL включены в public/fonts.
- Заголовок приветствия 32–36 px на телефоне и 44 px на ПК; «Пары» 38–42 / 48 px. Названия занятий 16–18 / 20–22 px, метаданные преимущественно 12–13 px. Поля поиска 16 px, подписи нижнего бара 10 px. Узкая недельная сетка сохраняет компактные подписи и открывает подробности по нажатию.

## Текущая пара и усиленный градиент — 03.11.2026

- Текущая пара на главной: отдельная плашка «Сейчас идёт», цветная точка, оставшееся до окончания время и заметный скруглённый прогресс-бар внутри карточки с отступами. Прогресс обновляется каждую секунду по московскому времени, в конце занятия карточка перестаёт быть текущей.
- Точка мягко мигает с периодом 2 секунды. При системном уменьшении движения мигание и анимация заполнения отключаются; состояние занятия и время продолжают обновляться.
- Аналогичные точка, время до конца и прогресс добавлены в карточки дневного календаря и подробностей. Цвета типов занятий сохранены.
- Фоновый градиент усилен в обеих темах: прохладный серый вверху справа и дополнительное мягкое свечение внизу слева, без движения фона.

## Локальное имя или никнейм — 03.11.2026

- В начале Настроек — поле «Имя или никнейм», до 64 символов, автоматическое сохранение в браузере. Это локальное предпочтение, без авторизации и передачи имени на сервер.
- Имя заменяет «Студент» в акцентной строке приветствия; аватар показывает первый символ имени в верхнем регистре. Пустое имя возвращает «Студент» и «С».
- Эмодзи, составные последовательности, флаги, модификаторы, кейкапы и невидимые управляющие символы отфильтровываются при вводе и чтении сохранённого значения. Разрешены буквы, цифры, пробелы и обычные знаки никнеймов (. _ - апостроф).
- Длинная строка не переносится и обрезается многоточием; полный текст сохраняется в поле настроек и title приветствия. Сброс локальных данных очищает и имя.

## Новый первый вход MyRSUH — 03.11.2026

- Три последовательных шага: знакомство → выбор группы → локальное имя и оформление. Существующий сохранённый выбор группы по-прежнему открывает приложение сразу.
- На первом экране — наш логотип, MyRSUH, статичный скриншот реального дневного расписания, заголовок «Все пары. Всё под рукой.», описание удобного расписания и «Далее» со стрелкой. Без выбора роли, регистрации и аккаунтов.
- Поиск группы по «ПИ», краткому названию, направлению и другим полям реестра. Результаты списком, выбор явно подтверждается зелёным цветом и галочкой. До выбора переход недоступен. Новые группы будут искаться по тому же реестру без фиктивных результатов.
- На последнем шаге — необязательное имя, две действующие темы с миниатюрами и четыре акцента. Готово сохраняет группу и открывает Главную. Имя без эмодзи; пустое имя остаётся «Студент». Настройки общие с основной страницей Настроек.
- Назад сохраняет выбор и введённые значения. Индикатор трёх шагов, плавные переходы вперёд/назад, перенос фокуса на заголовок. Учитывается prefers-reduced-motion.
- Меню выбора группы вынесено в Radix Portal в body: отдельный модальный слой над страницей, блюр 5 px с затемнением и мягкая тень. Клавиша Escape/клик снаружи закрывают меню; фокус ограничен меню, доступен переход во Все расписания. Позиция ограничена краями экрана и пересчитывается при изменении ширины.


## Актуальные уточнения

- Каталог содержит 27 групп ИИНиТБ. Группы ищутся по вводу при первом входе и на экране добавления. Сохранённые расписания можно переключать и удалять.
- Стрелки над полоской дней листают недели с сохранением дня недели. Короткое имя группы формируется из двух последних частей шифра.
- Ручное обновление по умолчанию отключено. В закрытой установке его можно включить через `RGGU_ALLOW_MANUAL_REFRESH=true`. Обычная загрузка использует кеш и обновляет его по истечении срока.
- Имя приложения и ярлыка — MyRSUH. Синий знак используется для вкладки и ярлыка, версии для светлой и тёмной темы — на экране знакомства.
